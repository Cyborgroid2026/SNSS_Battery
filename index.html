      결정 표면 무늬는 같은 보로노이 규칙으로 세포 크기만 ×12 확대해 그린 것이고, 상세도 A 는 실제 계산한 세포(1.34 × 1.34 × 3 mm)입니다. 층·극성은 없습니다. 2D 도면은 '실물 도면' 탭에 있습니다.

      병 속 식염수에서 결정이 바로 생겨 세포가 되는 과정의 2D 단면 모식도입니다 (보로노이 결정핵 + 프랙탈 동결 전선, 층·극성 없음). 같은 규칙으로 만든 3D 인공세포 조직은 CAD 작업대, 실제 절차(방향성 동결)는 실험대에서 볼 수 있습니다.

        표시는 이해를 위한 2D 단면 모식도입니다 (세포 크기 확대). 층·극성은 없고, 모든 세포가 같은 종류입니다. 실제 걸리는 시간은 실험으로 측정해 '실험 기록'에 남겨 주세요.

        비교용 · 이전 층 모델 — 이 탭은 묽은/진한 층이 번갈아 쌓인다고 가정했던 이전 모델의 해석입니다. 지금 구조(통째 결정 · 층·극성 없는 인공세포)는 CAD 작업대와 실험대에 있습니다.

        결정화 = 결정핵에서 자란 도메인들이 만나는 곳이 벽 → 보로노이 분할. 묽은/진한 층의 경계는 프랙탈 곡선, 결정핵 분포는 프랙탈 점집합. 아래 단면은 슬라이더에 따라 바로 다시 계산됩니다.

        전압·전력은 Python 보로노이 회로망 계산(상관도 , 결정핵 고른 분포 기준)을 D × 거칠기 지도로 미리 구해 보간한 값입니다. 정확한 값은 python3 -m snss_battery fractal.

        비교용 · 이전 층 모델 — 이 탭은 묽은/진한 층이 번갈아 쌓인다고 가정했던 이전 모델의 해석입니다. 지금 구조(통째 결정 · 층·극성 없는 인공세포)는 CAD 작업대와 실험대에 있습니다.
        
    
        생명체처럼 안에서 에너지를 만드는 방법(먹이) — 빛(광합성형), 내장 연료(소화형), 증발(호흡형), 레시피 반응물.
      에너지는 무에서 생기지 않으므로, 만드는 전력과 부하가 요구하는 전력을 같은 눈금으로 비교합니다. 그림은 Rust 렌더러가 그립니다.
        
    
        
    
        
  
        
  
        
    
        통째 결정 — 약국 식염수병 안 식염수에 PVA · GO 를 섞고, 병 그대로 아래에서 위로 얼립니다. 얼음 결정이 세포가 되고 GO·PVA 가 막이 됩니다.
      층도 극성도 없습니다. 자세한 설명·근거 문헌·위험 요소: RECIPE.md. 수치는 모델 예측입니다.
        
    
        
    
        만드는 순서 (요약)
        
    
          
    
          대조군 — 함께 만들 것
          
    
          
  
          
  
          
    
          생리식염수 결정 자체는 양자 배터리가 될 수 없습니다 (상온 물속 이온의 결맞음은 펨토초 안에 사라짐).
      그래서 금속·생물 요소 없이 만들 수 있는 진짜 양자 배터리를 별도 모듈로 설계했습니다: 유기 색소 분자를 유전체 거울 미세공진기에 넣은
      Dicke 형 (Quach 외, Science Advances 2022 에서 집단 초흡수 실증). 계산은 Python·Rust·C# 3중 구현, 형상은 Rust(truck B-rep 커널)·C#(STEP 작성기)로
      만들고 OpenCascade 로 검증했습니다.
          
    
          
    
          
    
          충전 시뮬레이션 (Tavis–Cummings, 광자 N 개 → 분자 N 개)
          
    
          
    
          계산 교차 검증
          
    
          
    
          CAD — STEP (ISO 10303-21, AP214) · OpenCascade 검증
          
    
          
    
          
    
          STEP 파일은 FreeCAD · Fusion 360 · SolidWorks · Onshape · CATIA 등 어떤 CAD 에서도 열립니다.
      나노미터 층이 있으므로 CAD 에서 확대해서 보세요. 결정 블록 STEP 은 도메인 층 252개 + 벽 252장(고체 504개)입니다.
          
    
          
  
          
  
          
    
          ① 계산 재현성 — Python · Rust · C# 독립 구현 비교
          
    
          같은 명세(spec/SPEC.md)를 세 언어로 따로 구현했습니다. 같은 난수(SplitMix64)·같은 입력에서 같은 숫자가 나오면
      결과가 특정 언어나 라이브러리의 산물이 아니라는 뜻입니다. (보로노이: Python 은 Qhull, Rust·C# 는 직접 짠 반평면 절단)
          
    
          
    
          
    
          ② 실험 판정 — 사전 등록 가설 (C# 판정기)
          
    
          계산이 맞아도 실제 전기가 나오는지는 실험만이 증명합니다. '실험 기록'에 측정값을 넣으면 아래 가설이 자동 판정됩니다.
