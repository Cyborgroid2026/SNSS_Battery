# 실험대 19단계의 현실 물리 명세 (`benchphys.py`)

`process.py` 의 19단계(같은 id)마다 실제 물성으로 무엇이 일어나는지 · 얼마나 걸리는지 · 레시피 시간이 맞는지 계산한다.
이 숫자가 웹 '실험대' 탭의 **물리** 칸과 그림(소용돌이 · 기포 · 김 · 얼음 전선 · 겔 처짐), Blender 물리 엔진 렌더
(`sim/blender_bench.py` — Mantaflow 유체 · Bullet 강체), 발표 자료(`report/make_pptx.py`)를 함께 움직인다.

명령: `./tools.sh bench-physics` (= `python -m snss_battery bench-physics`) · 시험: `tests/test_benchphys.py`.

## 1. 물성 (25 °C 근처)

- 물: 점도 Vogel 식 `μ = 2.414·10⁻⁵ · 10^(247.8/(T+133.15))` (20 °C 1.00 · 90 °C 0.31 mPa·s),
  포화 증기압 Antoine 식 (1–100 °C), 증발 잠열 `2.501·10⁶ − 2370·T` J/kg, 열용량 4180 J/kg·K.
- PVA 수용액 (Mw 약 9만, 99 % 가수분해 기준): 4 wt% 가 20 °C 에서 28 mPa·s (제품 규격값). 농도 · 온도 의존성은 **가정** —
  얽힌 영역(4 % 이상) `η ∝ c⁴`, 그 아래 `η ∝ c²`, 온도는 아레니우스 `Ea = 25 kJ/mol`.
  → 15 % 원액 20 °C 5 537 · 90 °C 767 mPa·s, 섞인 3 % 15 mPa·s.
- GO: 판 하나 1 µm², 면밀도 1.2 mg/m² (산소기를 단 단층, **가정**), 응집 덩이 프랙탈 차원 1.8.
- PVA 크라이오겔 탄성률 `E = 0.35 kPa · c² · n^½` (c wt%, n 동결-해동 횟수 — 10 % · 3회 ≈ 60 kPa 에 맞춘 **가정**).
- '가정' 이 붙은 값은 시험으로 바꿔야 한다. 계산은 모두 닫힌 식 · 작은 상미분방정식 (손으로 따라갈 수 있음).

## 2. 단계별 식

| 단계 | 식 · 입력 |
|---|---|
| 1 냉각판 예냉 | `t = C ΔT / (P − 새는 열)` — 알루미늄 판 300×300×10 mm + 부동액 2 L, 냉각 능력 200 W (가정) |
| 2 계량 | 공기 부력 보정 `m (ρ_공기/ρ_PVA − ρ_공기/ρ_분동)` (PVA 1.27 · 분동 8.0 g/cm³) |
| 3 덜어 내기 | 병목 꿀럭 흐름 `Q ≈ 0.25 √g d^(5/2)` (d 22 mm) · 모세관 길이 `√(σ/ρg)` |
| 4 PVA 분산 · 8 섞기 | 자석 막대 `Re = ρ N L²/μ` · 소용돌이 `Δh = (κ_eff ω L/2)²/g`, `κ_eff = 0.6 (1 − e^(−Re/500))` (가정) · 섞이는 시간 Grenville 상관식 (출력수 1 가정) · 알갱이 스토크스 |
| 5 PVA 용해 · 6 식히기 | `m c dT/dt = P(온도 제어) − h A (T − T∞) − L ṁ`, `ṁ = f h_m A_윗면 (ρ_v(T) − ρ_v,∞)` — h 10–12 W/m²K, `h_m = h/(ρc Le^⅔)`, 호일로 새는 몫 f = 5 % (가정), 핫플레이트 유효 150 W (가정) |
| 7 예비 시험 | 스몰루호프스키 빠른 응집 `t½ = 3 μ W / (4 kT n₀)` · CCC = 44 mM (1 + 0.15·PVA%) · 덩이 `a N^(1/Df)` · 실효 밀도 `Δρ (R/a)^(Df−3)` · 스토크스 |
| 8 섞기 | 담쾰러 수 `Da = 섞이는 시간 / 응집 반감기` |
| 9 기포 빼기 | 보일 `r ∝ (p₀/p)^⅓` · 스토크스 떠오름 · 끓는 압력 = 22 °C 포화 증기압 |
| 10 병에 담기 | 누셀트 액막 `δ = (3 μ Γ / ρ² g)^⅓`, 물결 없는 한계 `Re_막 = 4Γ/μ < 30` |
| 11 동결 세팅 | 바닥 열전달 `1/U = t_틈/k_틈 + t_PET/k_PET` (틈 0.2 mm, 공기 vs 30 % 에탄올) |
| 12–14 동결 · 해동 | FEniCSx 축대칭 열전달 결과 (`spec/fenicsx_freezing.json`) — 가운데 기둥의 전선 도착 시각 → 전선 높이 · 속도 |
| 15 꺼내기 | 제 무게 `σ = ρ g H` · 변형 `σ/E` · 푸아송 0.5 로 바닥 부풂 |
| 16 전압 | 원통 첫 모드 `τ = R² / (5.78 α)` · 염수 열전위 0.2 mV/K (가정) |
| 17 급속 고정 | 막비등 `h ≈ 150 W/m²K`, 덩어리 계산 `τ = ρ c (V/A) / h` |
| 18 동결건조 | 마른 층 열전도 한계 승화 `t = ρ_얼음 ΔH_s φ d² / (2 k ΔT)` |
| 19 SEM-EDS | 카나야–오카야마 전자 퍼짐 `R = 0.0276 A E^1.67 / (Z^0.89 ρ)` (마른 겔 0.2 g/cm³) |

## 4. 계산이 알려 준 것 (정직하게)

- **식히기 66 분 vs 레시피 42 분**: 공기로만 식히면 더 걸림 — 비커를 찬물 그릇에 담그면 몇 분. 증발 보충은 뜨거울 때 (식는 동안 더 줄어드는 양은 1 g 남짓).
- **GO 응집 — 예비 시험이 '중단' 쪽으로 나올 가능성이 큼**: 섞인 염 135 mM 이 CCC 64 mM 보다 진해 반감기 7 s.
  본 섞기에서는 섞이는 데 86 s 라 `Da ≈ 12 ≫ 1` — GO 가 넣는 자리에서 먼저 엉김. 가늘게 · 소용돌이 벽 쪽으로 넣고,
  PVA 가 GO 를 감싸 늦추는지(안정도 비 W > 1)를 예비 시험이 가려야 한다.
- **꺼낼 때 처짐 23 %**: PVA 3 % · 3회 크라이오겔은 약 5.5 kPa 로 계산돼 제 무게(1.3 kPa)에 키가 약 15 mm 줄고 바닥이 부풂 (탄성률 식은 가정).
  병째 잘라 받친 채 바로 재고, 눕히지 말 것.
- **전압 측정 전 온도 고르게 24 분**: 레시피의 '10 분 안에' 재면 윗·아랫면 온도 차가 0.1 mV 급 거짓 전압을 만들 수 있음 — 정 · 역 측정 + 양면 온도 기록.
- **SEM-EDS 15 kV 는 31 µm 로 퍼짐**: 마른 겔(0.2 g/cm³)에서 얇은 벽과 칸 신호가 섞임 → 5–10 kV.
- 나머지(예냉 · 계량 · 붓기 · 기포 · 동결 · 해동 · 급속 고정 · 동결건조)는 레시피 시간 · 방법이 물리와 맞음.

## 5. 웹 '실험대' 에 들어간 것

- 오른쪽 **물리** 칸: 엔진 표시(Mantaflow 유체 · Bullet 강체 · FEniCSx 열전달 · 해석식), 값 표, 판정(✔ / ⚠), 곡선(가열 · 식힘 온도, 응집 덩이 크기, 얼음 전선, 탄성률).
- 그림: 핫플레이트 온도 = 가열 · 식힘 곡선, 김의 양 ∝ 포화 증기압, PVA 분산 · 섞기 비커의 소용돌이 깊이 (×3 과장, 단계끼리 비율 그대로),
  가라앉는 PVA 알갱이 (스토크스 속도), 기포 빼기의 큰 · 작은 기포가 스토크스 속도 그대로 실시간으로 떠오름,
  방향성 동결 · 재동결의 얼음 전선 = FEniCSx 가운데 기둥, 꺼낸 겔이 제 무게로 처지고 바닥이 부풂.
