# SNSS 빛 조각가 SC-2 명세 — 펜 없이, 배지가 모니터

배양조 속 **멸균생리식염수(배지)가 곧 모니터**다. 데스크톱에서 설계한 존재가 화면 대신 배지 속에 결정으로 맺힌다.
펜도 갠트리도 없다. 결정을 만드는 것은 **배지 속 물질(잉크층)** 과 **전자기파(405 nm 빛)** 뿐이다.

코드: `lightsculpt.py` (§2–5) · `layout.py` `make_light_layout` (§6) · CLI `python -m snss_battery light` · 시험 `tests/test_light.py`.
**가정**이라 적힌 값은 문헌 범위의 출발값 — 첫 시험편(`light coupon`)으로 재서 바꿔야 한다.

## 1. 한눈에

| 항목 | 내용 |

| 잉크층 | 떠 있는 PETG 테(안 150 mm) 안, 배지 위에 뜬 10 mm 층: NaCl 10 mM · GO 2 mg/mL · 감광 PVA(PVA-SbQ) 1 % · NBD 1 mM · 에오신 Y 10 µM (225 mL) |

| 물속 기계 | 받침 + 기둥 + Z 나일론 나사봉 3 (모터 방수 통 · 자석 커플링) + 흑연 패드 · 전극뿐 |

## 2. 잉크층 — 왜 떠 있고, 왜 내려가면 굳나

- CCC = 44 mM × (1 + 0.15·PVA%) = 51 mM (SC-1 과 같은 가정).
  잉크 10 mM < CCC → GO 가 엉기지 않고 떠 있음. 배지 154 mM > CCC → 내려간 층은 엉기며 고정.
- 밀도 (SC-1 식): 잉크 1000.5 < 배지 1003.3 kg/m³ → 잉크층이 위에 뜸 (차이 0.5 미만이면 실패로 봄).
  PVA 를 5 % 로 올리면 잉크가 가라앉는다 — 감광 PVA 를 많이 못 넣는 이유.
- 잉크 수명: 경계에서 염이 확산(D = 1.5×10⁻⁹ m²/s)해 노광면이 CCC 의 80 % 가 될 때까지 `c = c_잉크 + Δc·½erfc(d/2√Dt)` → 14 h.
  그보다 오래 걸리면 잉크를 갊.
- 양이온 고분자(PEI)는 GO 를 엉기게 하므로 잉크에 넣지 않음 → n 도펀트는 없다. p 도핑은 빛으로 (§3a).
- 잉크 염 = NaCl + NBD(BF₄ 염) 가 CCC 아래여야 함.

## 3. 빛 — 굳힘과 광환원

- 침투 깊이 `Dp = 1 / (ln10 · (ε_GO·c_GO + a_SbQ·PVA%))`, ε_GO(405 nm) = 15 mL·mg⁻¹·cm⁻¹ (가정), a_SbQ = 1.5 /cm/% (가정) → 0.138 mm.
- 굳는 깊이 `Cd = Dp·ln(E/Ec)` (SLA 작업 곡선), Ec = 20 mJ/cm² (가정). 층 바닥 + 25 % 까지 굳힘 → 막 노출 306 mJ/cm².
- 세포질 = 누적 E_red = 1 J/cm² 이상 (GO → rGO, 상온 광환원, 가정). 막 = 누적 θ·E_red = 0.3 J/cm² 아래 (GO 그대로, 가정).
- **위층 빛이 아래로 샘**: 세포질 기둥 바로 아래 막 칸이 받는 누적량 / E_red = `e^(−x) + (E_막/E_red)·(1 − e^(−x))/x`, x = 층/Dp.
  이 값이 가장 작은 x = 2.18 로 층 두께를 정함 → 층 0.301 mm, 막 0.24·E_red < θ.
- 층 그림 (`exposure_plan`): 칸 기둥마다 맨 위층부터 — 위층에서 새어 온 빛 `Q` 를 빼고 모자란 만큼만 비춤.
  `D_k = c·(E_k + Q_k)`, `Q_k = r·(E_{k+1} + Q_{k+1})`, `r = e^(−x)`, `c = (1 − r)/x`.
  점검: 세포질 rGO 비율 · 막이 샌 비율 · 아래가 빈 돌출부 밑 잉크가 원치 않게 굳은 양.

## 3a. 빛으로 p 도핑 — 초록 530 nm

- 한 색으로는 p/n 을 가를 수 없다: 세포질은 모두 광환원 노출을 받아야 하기 때문.
- 그래서 두 번째 색: 잉크 속 **에오신 Y**(금속 없는 광산화환원 색소, C·H·O·Br·Na)가 530 nm 에 들뜨면 NBD(디아조늄)를 환원해
  아릴 라디칼이 rGO 에 붙음 (가시광 광산화환원 아릴화, König 외 2012) → **초록을 받은 p 세포만 p 도핑**.
- 접목 `f = 1 − e^(−D_g/E_g)`, E_g = 300 mJ/cm² (가정), 목표 80 % → 누적 483 mJ/cm², 다 붙으면 정공 5×10¹² cm⁻² (가정).
  초록 침투 `Dp_g = 1/(ln10·(ε_GO,530·c_GO + ε_eosin·c_eosin))` = 0.207 mm (ε_GO,530 = 10 가정, ε_eosin = 95 000 M⁻¹cm⁻¹).
- 층 그림은 405 nm 와 같은 기둥 풀이 (`_columns`) — 위층 초록이 막 너머 n 세포로 새는 것까지 셈. n 세포 허용 = 10 % + 잉크 속 저절로 붙는 몫
  (`1 − e^(−t/48 h)`, 가정 — 잉크층을 지나는 동안만, 배지에 들어가면 NBD 가 없음).
- 결과 (서 있는 존재): p 세포 82 % (4.1×10¹² cm⁻²) · n 세포 10.6 % (대부분 저절로) · 허용 넘은 n 칸 0 % · 에너지 0.020 → 0.024 J (×1.19).
  초록을 따로 비추므로 시간이 늘어남 (28 → 38 h).

## 4. 상온 — 빛 세기의 상한, 그리고 시간

- 잉크가 빛을 거의 다 흡수 → 표면 온도 상승 `q / (k_물/잉크층 + 10 W/m²K)` ≤ 1 K → 빛 세기 약 7 mW/cm² 이하.
- 배지 전체: 빛 0.7 W + Z 모터 1.0 W + 데스크톱(단열판 너머) 0.7 W → +0.42 K (벽 · 수면 5.8 W/K).
- 세포질 기둥은 층마다 E_red·x 가 들어가므로 높이당 E_red/Dp — **제작 시간 ≈ E_red·H / (Dp·I)**.
  GO 를 진하게 하면 Dp 가 줄어 느려지고, 빛을 세게 하면 상온이 깨진다. 이것이 이 기계의 근본 맞교환.

## 7. 하지 않는 것 (정직하게)

- n 도핑 없음 — 빛으로 n 도펀트를 붙이는 상온 방법을 아직 찾지 못함 (PEI 는 GO 를 엉기게 해 잉크에 못 넣음). p · 약한 p 셀 (×1.19).
- 초록 접목 상수(E_g · 정공 밀도 · 저절로 붙는 시간)도 가정 — 시험편으로 잴 것.
- 모든 빛 상수(ε_GO, Ec, E_red, θ)는 가정. 특히 **E_red(상온 광환원 누적량) 와 θ(막이 절연을 지키는 문턱)** 가 시간과 성공을 정한다 — 시험편으로 먼저 잴 것.
- 옆으로 퍼지는 빛(산란)은 셈하지 않음. 막이 한 칸(0.41 mm)이라 산란이 크면 옆 막도 환원될 수 있다.
- 오목하게 닫힌 곳의 잉크는 몸을 따라 내려가 엉긴다 — 설계에 닫힌 빈 곳을 두지 말 것.
- 존재는 스스로 에너지를 만들지 않는다 — 밖에서 충전해야 깨어난다.

## 8. 빛 상수 보정 — 시험편 사다리 (`lightcal.py`, `light-cal`)

가정값을 실측으로 바꾸는 순서. 멀티미터 · 캘리퍼스 · 흑연 기준 전극이면 된다.

| 시험 | 먼저 | 사다리 (12칸, 8 mm) | 잴 것 | 맞춤 → 상수 |
|---|---|---|---|---|
| A 굳힘 | 없음 | 405 nm 30–1200 mJ/cm² | 굳은 두께 Cd | `Cd = Dp·ln(E/Ec)` 직선 → Dp · Ec, Dp → ε_GO |
| B 광환원 | 모든 칸 굳힘 | 405 nm 50–4000 mJ/cm² | 2단자 저항 R | `log σ = a + b(1 − e^(−D/τ))` → E_red = τ·ln10 (로그 상승 90 %) |
| C 초록 접목 | 모든 칸 다 환원 | 530 nm 30–1800 mJ/cm² | 개방 전위 차 ΔV | `ΔV = ΔV_max(1 − e^(−D/E_g))` → E_g, 정공 = (eΔV_max/ħv_F)²/π |
| D 전기 도핑 (§10) | 모든 칸 다 환원 | PEI 도핑 통, 칸마다 −0.8…+0.4 V · 24 h | 개방 전위 차 ΔV | `ΔV = ΔV_max/(1 + e^((E − E½)/w))` → E½ · w · n_max |
| E 주입량 (§11) | 모든 칸 다 환원 (`coupon_EF.png`) | T1 피펫으로 PEI:GO 0.02–1.5 (`coupon_EF_inject.gcode`) · 24 h | T5 탐침 ΔV | ΔV → n, `n = n_max(1 − e^(−r·ln10/r_sat))` → r_sat (90 % 비) · n_max |
| F 막 너머 샘 (§11) | 같은 판, 막 한 줄로 붙인 칸 짝 2개 | 짝 중 하나에만 r_sat 만큼 주입 | 두 칸 ΔV | 샘 = (ΔV_이웃/ΔV_주입)² |

- 사다리 그림은 밝기 일정 · 칸마다 켜 두는 시간이 다른 회색조 한 장 (DLP 의 PWM 과 같은 방식).
- θ(막 절연 문턱)는 맞춤값이 아니라 **정의**: 막 노출이 로그 전도도 상승의 50 % 를 넘지 않으면 (6 자릿수 상승이면 세포질보다 3 자릿수 낮음)
  전자를 막는다고 봄 → θ = ln2/ln10 = 0.30. 30 % 로 엄하게 잡으면 θ = 0.155 가 되어 지금 층 설계가 **실패**한다 (막 새는 빛 0.24) —
  막 기준이 이 기계의 성패를 가르는 숫자다.
- `python -m snss_battery light-cal coupon` → `sculpt_out/light_cal/` (coupon_A/B/C.png · measurements.csv · README.txt)
  → 측정값을 채워 `light-cal fit measurements.csv` → `sculpt_out/light_cal.json` → `light being --cal sculpt_out/light_cal.json`.
  웹 콘솔은 `light_cal.json` 이 있으면 그것을 씀. `light-cal demo` 는 참값을 아는 가상 측정으로 맞춤을 연습 (참값을 3 % 안에서 되찾음).
- 웹 콘솔 '시험편 측정 → 빛 상수 보정': 사다리 네 개의 표에 측정값을 적고 **맞추기 · 저장** (서버 `/api/lightcal` 이
  `sculpt_out/light_cal/measurements.csv` 와 `light_cal.json` 을 씀). **연습값 채우기**로 맞춘 것은 `light_cal.json` 에 저장하지 않음.

## 9. 실제 기계 묶음과 실행기 (`lightrun.py`, `light --export`, `light-run`)

- `job.gcode` · `printer_light.cfg`: Klipper 기록 · 설정 (Z 나일론 나사봉 3 = `z_tilt`, 1회전 1.25 mm, `PROJECT` · `INK_SWAP` · `LEAK_CHECK` · `CURE` 매크로).
- `light-run <machine 폴더>`: 기본은 시간표만. `--window` 는 프로젝터 창 (`--geometry 1920x1080+1920+0` 로 프로젝터 출력 화면에 전체),
  `--moonraker http://…` 면 층마다 Z 를 Klipper 로. 방수 키보드: Space 멈춤/이어서 (잉크 갈기 뒤 이어서도 Space) · Esc 그만.
  시작 · 멈춤 · 끝 · 그만 때 늘 먼저 검은 화면.

## 10. 사후 전기 도핑 — n 세포 (`electrodope.py`, `light --edope 24`)

빛으로 n 도핑하는 상온 · 금속 없는 방법은 아직 없다. 후보였던 벤질 비올로겐(BV⁰, 빛 + 희생 전자 주개로 만듦)은 강한 n 도펀트지만
배지 속 녹은 산소에 곧 산화돼 도핑이 사라지므로 버림. 대신 **존재 자신의 배선**(간극연접으로 이어진 + 망 · − 망)으로 전기장을 건다.

- 다 빚은 뒤 받침째 꺼내 도핑 통(멸균생리식염수 1 L + 분지형 PEI 0.1 %, 흑연 상대 · 연필심 기준 전극)에 담금.
  오른발(− 망) −0.6 V · 왼발(+ 망) +0.2 V (흑연 기준, 탄소 안전 전압창 안).
- PEI(양이온 고분자)가 붙는 몫 `f(E) = 1/(1 + e^((E − E½)/w))`, E½ = −0.2 V, w = 0.08 V (가정) → − 망 99 % · + 망 0.7 % · 단자에 안 이어진 세포 8 %.
- 몸 속으로는 확산: 깊이 d 의 세포는 `erfc(d / 2√(Dt))`, D = 5×10⁻¹¹ m²/s (PEI 25 kDa 가 젤 속, 가정). 순 도핑 = PEI 전자 − 빛으로 붙은 NBD 정공.
  양자층은 세포 용량 가중 평균 도핑 하나로 어림.
- 서 있는 존재: 24 h → n 세포 40 % 가 절반 이상 · 에너지 0.024 → 0.031 J (×1.29). − 망 세포 90 % 가 절반 이상 붙으려면 약 156 h (6.5 일) → ×1.36.
  도핑 없을 때(0.020 J)보다 ×1.55. **한계: 확산이 느려 몸 속 깊은 세포는 덜 도핑된다.**
- 보정: 사다리 D (§8) → `light being --edope 24 --cal sculpt_out/light_cal.json` 이 맞춘 E½ · w · n_max 를 씀. 확산 계수 D 는 아직 가정 (두꺼운 덩어리를 잘라 단면으로 잴 것).

## 11. 조각 도구 — 물속 갠트리 + 주사기 (`lighttools.py`, `light --tools`, `light-tool`)

빛이 몸(보로노이 세포)을 층층이 빚고, 주사기와 도구가 빛이 못 하는 것을 한다. 물속 CoreXY 갠트리 (SC-1 과 같은 탄소섬유 · PETG · 나일론,
모터는 방수 통 · 자석 커플링) + 자석 키네마틱 도구 교환 + 뒤쪽 도구 걸이.

| 도구 | 끝 (물속, 금속 없음) | 쓰임 |
|---|---|---|
| T0 쌓기 주사기 | PEEK 노즐 Ø0.41 + 나선 혼합기 (GO · SNSS · PVA) | 허공 획 · 덧붙이기 · 메우기 — SC-1 레시피, 잉크 자체 염(62–69 mM > CCC)으로 굳음 |
| T1 주입 주사기 | 당겨 뽑은 유리 미세 피펫 (붕규산, 끝 Ø0.1, 30 mm) | n 세포마다 PEI 1 % 주입 · 잉크 · 수리액 |
| T2 흡입 주사기 | PEEK 관 Ø1.0 | 깎기 · 떼어 낸 조각 회수 |
| T3 나일론 줄 칼 | 낚싯줄 0.2 mm · PETG 활 | 떼기 |
| T4 누름판 | PETG 20×20 + 실리콘 | 붙이기 (30 분 아묾) |
| T5 흑연 탐침 | 연필심 0.3 mm × 2 | 세포 개방 전위 · 저항 |

- **두 작업면**: 빛 면 = 수면 330 mm (갠트리는 뒤쪽 (0, 105) 에 주차 — 받침 기둥 · 빛길 비킴) · 도구 면 = 도구 끝 198 mm
  (멸균생리식염수 속 — 받침이 작업물 꼭대기를 여기로 내림, SC-1 환경 그대로).
- **배치 맞춤** (`layout._tool_gantry`): 갠트리 304 mm (X 빔 283–316), 잉크 우물 테는 잉크층 밑 2 mm(318)까지만, Z 나사봉 280 mm 까지 ·
  받침 기둥 52 mm, XY 모터 통 (±121, 95) (프레임 꼭짓점 비킴), 주사기 펌프 왼벽 4 (GO · SNSS · PVA · PEI) + 오른벽 1 (흡입 회수).
- **도구 높이 한도 82 mm**: 도구 면까지 내렸을 때 받침 너트 판이 Z 모터 방수 통(46) 위에 머물러야 함 → 서 있는 존재 73 mm 는 됨.
  넘는 작업(예: 존재 + 10 mm 싹)은 거절.
- **주입 n 도핑**: 빛으로 9 mm 쌓을 때마다 도구 면으로 내려 **한 띠 아래** n 세포에 주입 (위 띠가 덮개 — PEI 가 잉크층에 닿아 GO 를
  엉기게 하지 않게), 마지막 띠는 다 빚은 뒤. 세포질의 10 % 를 PEI 1 % 로 (PEI : GO = 0.5, 포화 가정), 세포 안 스밈 τ = r²/(π²D) ≈ 1.4 h
  — 다음 띠를 빛으로 쌓는 4 h 동안 끝남. 막 너머 새는 몫 5 % (GO 막이 붙잡음, 가정).
  서 있는 존재: n 세포 524개 · 9번 · 도구 작업 1.6 h · n 세포 100 % 가 절반 이상 · 에너지 0.024 → **0.033 J (×1.38)**.
  몸 통째 담그는 전기 도핑(§10, 24 h ×1.29 · 6.5 일 ×1.36)보다 빠르고 고르다.
- **주사기 조각** (`light-tool add|carve|detach|draw|attach`): SC-1 의 작업 함수를 이 기계 격자로 그대로 → G-code 에서 홈 잡기 · 배지 채우기를
  빼고 도구 면 · 도구 집기(`TOOL_PICK T=…`) · 주차(`GANTRY_PARK` · `SC2_LIGHT_PLANE`)를 넣음. 기억은 그 빛 작업 폴더에.
- 실행 묶음(`light --tools --export`): `tools/inject_NN.gcode` · `job.json` 의 층마다 `tool_before` · 다 빚은 뒤 `tool_after`.
  실행기는 그 자리에서 빛을 끄고 Moonraker 로 주입 G-code 를 보냄 (없으면 미리보기로 시간만).
- 열: 도구를 쓰는 동안 배지 +0.90 K (모터 8개) · 평균 +0.44 K.
- **EIT 와의 충돌 해결** (spec/EIT.md): 슬리브(288 mm 까지)는 갠트리 쓸림(283–316)과 겹쳐서, 기본 전극 자리를 **잉크 우물 테 치마 안쪽 (z 319)
  + 배양 받침 테두리 (받침과 함께 움직임)** 로 바꿈. 대가: 덧굳은 12 mm 덩어리는 한 층 안에 안 보이고 10층 평균(약 1.5 h)이면 보임 (한 층이면 16 mm 부터).
  자람은 층마다 뚜렷 (신호/잡음 44). `./tools.sh light-eit [--compare]` · 웹 콘솔 'EIT' 칸.
- 주입 포화는 `1 − e^(−r·ln10/r_sat)` (r_sat 에서 90 %, 시험 E 와 같은 식) · 주입량 세포질의 15 % (PEI:GO 0.75 → 97 %).
- 웹 콘솔: 층 슬라이더 아래 눈금 (주황 = 잉크 갈기, 초록 = 도구 작업) · 그 층으로 가면 3D 에 갠트리가 펴지고 받침이 도구 면으로 · 시간표는
  `lightrun.plan_schedule` (기계 묶음과 같은 계산).
- Blender 한 주기 동영상: `./tools.sh light-blender --anim` → `light_cycle.mp4` (빛 → 빛 끔 · 갠트리 폄 · 받침 내림 → 유리 피펫 주입 → 주차 · 올림 → 다음 층 빛).
  아직 빚지 않은 층은 작업물 좌표로 잘라서 받침이 오르내려도 맞음.
