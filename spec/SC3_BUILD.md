# SC-3 영점 막대 + 수조 콘솔 — 실제로 만들기

`snss_battery/sc3_build.py` 한 곳에 모든 부품(출력 · 산 것)의 자리 · 받침 · 조립 단계가 있고, Blender 'SC-3 영점 막대' 장면은
그 자리대로 그린다 (출력 부품은 여기서 SDF 로 만든 STL 그대로). 만들기 전에 늘:

```bash
python3 -m snss_battery sc3 build     # cad_out/sc3/ — stl/ (출력 16종) · parts.csv · buy.csv · ASSEMBLY.md (조립 16단계) · layout.json
python3 -m snss_battery sc3 check     # 조립 점검만
```

## 1. 조립 점검 (`sc3_build.check`)

| 점검 | 무엇을 |
|---|---|
| 출력 크기 | 출력 부품 16종이 모두 흔한 FDM 베드 220 × 220 × 250 안 |
| 뜬 것 없음 | 부품마다 받치는 것(`on`)과 실제로 닿는지 — 바닥에 놓는 것(데스크톱 다리 · 깔개 · 모니터 발)은 밑면이 바닥 z −183 |
| 부딪침 | 고정 부품끼리, 그리고 팔(r 0…60 · 노즐 높이 110…270)을 끝까지 움직였을 때 |
| 노즐 틈 | 칸마다(쌓는 순서) 고르지 않은 노즐 끝 · 노즐 머리가 지금 껍질보다 얼마나 바깥인지 — 서 있는 존재에서 8.2 · 16.8 mm (껍질 0.41) |
| 닿는 범위 | 존재 반지름 24 ≤ r 60, 존재 높이 136…209 ⊂ 노즐 110…270 · 머리는 수면 아래 |
| 꺼내는 길 | 축받이 막대를 들면 막대 축 둘레 Ø57 가 수면까지 비어 있음 |
| 물속 금속 | 물에 잠기는 것(막대 · 팔 관 · 머리 · 노즐 · 흑연)에 금속 없음 |

## 2. 주사 — 재료마다 노즐 따로

전에는 주사기 넷(GO p · GO n · GO 막 · PVA)이 **노즐 하나**로 합쳐졌다. 그러면 p 에서 n 으로 바꿀 때 혼합기 · 노즐 안에 남은 p 잉크가
n 자리에 나가 + 와 − 가 섞인다 (전지라면 합선). 그리고 노즐이 아래를 보고 있어 존재의 아랫면에는 닿지 못했다.

이제:
- **노즐 셋** (p · 막 · n) — PEEK 1/16" × Ø0.41, 노즐 머리에서 수평으로 막대 축을 봄 (아랫면도 옆에서 쌓음).
- 노즐마다 **제 혼합기** — GO 통 하나 + PVA 한 갈래가 처음 만남. PVA 는 펌프 하나 → 핀치 밸브 셋 (고른 노즐만 열림).
- 노즐 셋이 팔 관 둘레에 **30°** 씩. 팔 관 위(물 밖)의 MG90S 서보가 팔 관을 ±30° 돌려 고른 노즐 하나만 막대 쪽을 보게 함 —
  나머지 둘은 옆으로 비켜 이미 쌓인 껍질에 닿지 않음 (노즐 틈).
- 405 nm 빛: 물 밖 LED 둘 → PMMA 광섬유 Ø0.5 → p · n 노즐 옆 (고른 쪽만 켬). 막은 끔.
- 쌓는 순서: 껍질 → **재료** → 높이 → 각도 — 한 껍질에서 노즐 바꿈은 많아야 세 번 (서 있는 존재 271 번).
- 바꿀 때마다 (SD 프로그램에 구움): 팔을 5 mm 물려 고르개를 돌리고(0.4 s, 흐름 없음) → 새 노즐로 1 µL 밀어냄(쉬는 동안 끝에 엉긴 것 · 식염수) → 이어서.
  서 있는 존재에서 약 6 분 더 걸림.
- SD 채널 10: 막대 θ · r · z · GO p · GO n · GO 막 · PVA · 405 nm · 트리거 · **nozzle** (p −30° · 막 0 · n +30°).

## 3. 기계 (수조 위, 물 밖)

| 부분 | 만드는 법 |
|---|---|
| 틀 | 수조 테 안장 4 (유리 벽을 실리콘 띠째 뭄) → 2020 보 420 × 2 (y ±150) → 가로대 320 × 2 (x ±150, L 브래킷) |
| 막대 축 | 축받이 막대 2020 (y −45, 두 가로대에 걸쇠 + 손나사) 위 축받이: 608 × 2 · 막대 집게(60T) · NEMA17 + 20T · 닫힌 GT2 188 (3:1). 걸쇠를 풀면 막대째 위로 — 존재가 달려 올라옴 |
| 막대 | PC 관 Ø6/4 × 320 + 흑연 봉 Ø2 × 300 두 줄 (끝 12 mm 드러남, 윗끝은 물 밖에서 도전성 에폭시로 전선) |
| 팔 r | 팔 보 2020 × 150 (y +35) 위 MGN9 150, NEMA17 + 열린 GT2 |
| 팔 Z | r 판(Z 기둥) 의 MGN9 200 + NEMA17 + T8, Z 집게가 탄소 관 Ø10/8 × 400 을 6800 × 2 로 잡음 (고르개로 돎) |
| 펌프 | SC-1 주사기 펌프 × 4 (펌프 받침으로 펌프 가로대에) · SC-1 핀치 밸브 × 3 (밸브 판, 보 y +150) |

## 4. 수조 콘솔 · 바닥

| 부분 | 만드는 법 |
|---|---|
| 데스크톱 | IP67 방수 함체 약 360 × 360 × 110 (시중) + 고무 다리 4 — 바닥에 |
| 수조 받침 | XPS 30 → 아크릴 10 → EPDM 2 를 포개고 **모서리 잡이 4** (출력, VHB 로 함체 뚜껑에 — 구멍 없음) 안에 수조 |
| 모니터 | IP66 18.5" 1대 (F1–F4 로 화면) — **모니터 발**(출력, 바닥에) + 2020 × 300 기둥 + **VESA 75 판**(출력) |
| 입력 | 바닥 실리콘 깔개 위 IP68 키보드 · 마우스 → 앞판 IP67 USB |

## 5. 아직 정직하게

- 데스크톱 함체는 '약 360 × 360 × 110' 으로 잡았다 — 산 함체의 치수가 다르면 `console.Desktop` 값을 고치고 `sc3 check` 를 다시.
- 출력 부품의 모양은 SDF 기본형(상자 · 원기둥)으로 만든 것 — 풀리 · 기어 이는 근사다. 막대 집게의 60T · 기어는 0.25 mm 노즐로 뽑고 맞물림을 확인하거나, 시중 풀리로 바꿀 것.
- 부딪침 점검은 부품의 바깥 상자로 한다 (구멍 · 홈 속까지는 보지 않음). 노즐 틈만 칸 하나하나로 잰다.
- 쉬는 노즐 끝이 식염수 속에서 막히지 않는지 · 1 µL 로 충분한지는 시험편으로 재야 한다 (30 분 쉬게 한 뒤 다시 나오는지).
- 배선 · 데스크톱 속 아날로그 회로는 아직 그리지 않았다.
