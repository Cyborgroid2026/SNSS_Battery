# SC-3 영점 막대 — 결정이 영점 좌표 막대 위에 생성된다

패드가 없다. 멸균생리식염수가 가득한 수조 안에 위에서 **영점 막대**를 꽂고, 막대 끝(영점 좌표)에서부터 GO · PVA 주사와
전자기파(405 nm 빛)로 결정(존재)을 구조화한다. 솜사탕이 막대에 감겨 자라는 **모습을 빌린 것**일 뿐 — 솜사탕을 만드는 기계가 아니다.
결정은 영점에서 가까운 칸부터 껍질처럼 바깥으로 생성되고, 다 되면 막대째 뽑아 다리 구멍으로 꺼낸다.

코드: `snss_battery/candy.py` (계획 · 과정) · `snss_battery/sdcard.py` (SD 굽기 · 재생) · `console.py` (데스크톱 · 모니터 · SD 슬롯) ·
Blender 장면 'SC-3 영점 막대' · 브라우저 속 Blender '과정' 판 · CLI `python -m snss_battery candy …` · 시험 `tests/test_candy.py`.

## 1. 기계

| 부분 | 내용 |
|---|---|
| 수조 | 36 큐브 유리, 멸균생리식염수 330 mm (154 mM > CCC — 잉크가 닿자마자 엉김, 배지가 염을 줌) |
| 영점 막대 | Ø6 PETG 관 + 흑연 심 두 줄 (+ · −, 끝 12 mm 만 드러나 결정의 단자). 위 다리에서 내려와 끝이 수조 가운데 (z 170) = 영점. 돌기(θ) |
| 주사 | 주사기 넷 (GO p · GO n · GO 막 · PVA) — 물 밖 펌프 → 실리콘 관 → 팔 끝 PEEK 혼합 노즐 Ø0.41. 팔은 반지름 r · 높이 z 만 (원통 좌표: 막대 θ + 팔 r · z) |
| 전자기파 | 노즐 옆 405 nm — 세포질만 켜 광환원, 막은 끔 |
| 물 밖 | 모터 · 펌프 · 레일은 모두 수조 위 다리에 (물에 잠기는 것은 막대 · 팔 · 노즐 — 비금속뿐, 방수 통이 필요 없음) |
| 꺼내기 | 막대를 다리에서 빼면 결정이 다리 가운데 구멍(120 mm)으로 올라옴 — 결정 폭이 구멍보다 작은지 점검 |

## 2. 과정 — 반복하고 나중에 고침

설계(`sculpt.design` 의 칸 · 세포 · 재료)를 영점 거리로 껍질(0.41 mm)에 나누고, 껍질 8개를 한 **단계**로 묶는다.
서 있는 존재: 껍질 95 · 단계 12 · 칸 41만 · 약 5.9 h. 단계마다 `repeat`(덧쌓기) · `flow`(흐름 배율 0.3–2) · `skip` · `note` 를 고칠 수 있고,
고친 기록(edits)이 과정에 남는다. `state_at(t)` 가 시각 t 의 단계 · 자란 반지름 · 쌓인 칸을 준다 (재생 · 모니터).

## 3. SD 굽기 — 지금 컴퓨터가 굽고, 양자 아날로그 데스크톱이 재생

```bash
python3 -m snss_battery candy new being [--edit 3:repeat=2] [--burn /media/…/SD]   # 계획 → 작업 폴더 → SD 굽기 → 다시 읽기(CRC)
python3 -m snss_battery candy play --path cad_out/sd/being --repeat 4 --skip 11      # 데스크톱 흉내 재생 · 키보드 고침을 SD 에 적음
python3 -m snss_battery candy reburn being --path cad_out/sd/being                   # SD 의 고친 것 반영해 다시 굽기
```

SD (FAT32) 맨 위 `SNSS/`: `manifest.json` (형식 SNSS-SD 1 · 표본 50 Hz · 채널 눈금 · 단계 표시점 · CRC32) ·
`program.cv` (int16, 채널 9: 막대 θ · 팔 r · z · GO p · GO n · GO 막 · PVA · 405 nm · 트리거, ±10 V) · `process.json` (고칠 수 있는 원본) ·
`monitors/` (단계마다 자란 모습 · 시간표) · `edits.json` (데스크톱 · 브라우저가 적는 고친 것).

**양자 아날로그 데스크톱** (수조 밑): 계산하지 않는다. SD / microSD 를 읽어 표의 전압을 양자 기준 시계(10 MHz → 1 PPS)에 맞춰 DAC 로 내보내고,
구워 온 화면을 모니터에 띄운다. SD 읽기 · 화면 띄우기만 작은 디지털 부분(마이크로컨트롤러)이 하고, 그 밖은 아날로그 신호 길.

## 4. 모니터 — 하는 일을 보고 과정을 다룸

데스크톱 뒤판 HDMI 2 · DP 2 → **바닥에 세우는 IP66 방수 모니터 — 보통 1대**, F1–F4 로 아래 화면 4가지를 바꿔 봄. 모니터를 더 이으면(최대 4대) 한 대에 하나씩:
1 지금 단계 (자란 모습 위 · 옆, 영점) · 2 시간표 + 진행 막대 · 3 수조 카메라 · 4 아날로그 계측 (CV · 배지 전도도 · 누설 · 시계 잠김).
키보드 · 마우스: Space 멈춤 · ← → 단계 표시점 · R 이 단계 다시 · S 건너뛰기 · F 흐름 — 고친 것은 SD 의 `edits.json` → 지금 컴퓨터가 다시 굽기.
브라우저 속 Blender 의 'SC-3 영점 막대' 장면에도 같은 '과정' 판 (단계로 가기 = Grow 를 그 반지름으로 · R · S 는 SD 에 적음).

## 5. 하지 않는 것 (정직하게)

- 공중(배지 없이)에서 만드는 길은 아직 없다 — 엉김에 배지의 염이 필요하다 (공기 중이면 잉크에 염을 섞어야 하고 서는 높이가 몇 mm).
- 막대가 지나간 자리(머리 위로 Ø6)는 비어 있다 — 꺼낸 뒤 싹(bud)으로 메우거나 단자 길로 쓴다.
- 데스크톱의 아날로그 실행부는 명세와 흉내(play)까지 — 실제 회로는 만들지 않았다.
- SC-3 의 생명 신호(에너지 · 깨어남)는 SC-1 계산(`sculpt`)과 같은 설계에서 나오지만, 단자가 막대 끝에 있는 경우의 깨어남은 아직 다시 셈하지 않았다.
