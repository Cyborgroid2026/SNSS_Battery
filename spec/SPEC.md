세 구현은 이 문서만 보고 같은 숫자를 내야 한다. 기준 사례는 `spec/cases.json`,
판정 허용오차는 §9. 단위는 별도 표기가 없으면 SI (농도 mol/L, 길이는 표기대로).

## 1. 난수 (SplitMix64)

```
state ← seed (u64)
next(): state ← state + 0x9E3779B97F4A7C15 (mod 2^64); z ← state
        z ← (z ^ (z >> 30)) * 0xBF58476D1CE4E5B9; z ← (z ^ (z >> 27)) * 0x94D049BB133111EB
        return z ^ (z >> 31)
u()   = (next() >> 11) · 2^-53          ∈ [0,1)
uniform(a,b) = a + (b−a)·u()
poisson(λ): L=e^−λ, k=0, p=1; 반복 { p ← p·u(); p ≤ L 이면 k 반환; k ← k+1 }
round(v) = floor(v + 0.5)
```
seed 1 의 첫 next() = 10451216379200822465.

## 4. 병 → 결정 → 층 스택

- 병: 바깥지름 Do, 벽 0.8 mm, 용량 V [mL]. 내경 `Di = Do − 1.6`, 단면 `A = π(Di/20)²` [cm²], 높이 `h = V/A·10` [mm]
- 수축 s: `D = Di(1−s)`, `H = h(1−s)`, `Ag = π(D/20)²`
- 쌍 두께 `p = 2t + (5+8)/1000` [mm], `N = floor(H / p + 1e-9)` 쌍 (딱 맞는 높이의 반올림 오차 보정), 세포 부피 `Vc = Ag·t/10` [mL]
- 접촉면 그래핀 [mg]: 지정값 × Ag, 0 이면 `GO[mg] / (2N)` (`GO = c_GO[mg/mL]·V`)
- 태어남: `x = min(c0(r−1)/(r+1), c0 − 0.002)`, `q = 0` (r = 농도비). `cA = c0 − x`, `cB = c0 + x`
- 막전위/쌍 `E = (α_c+α_a)·Vt·ln(cB/cA)`, OCV `= N·E + 2q/C + E_evap`
- 저항/쌍 `(R_c+R_a)/Ag + t/(σ(cA)·Ag) + t/(σ(cB)·Ag)` (t, Ag 는 m, m²), 전체 `N·R_pair + 0.2 (+ 2·ASR/Ag 반응 접촉면)`
- 용량: 이온 `(c0−0.002)·Vc[L]·F/η` (`η = (α_c+α_a)/2`), 접촉면 `C·0.6`, 작은 쪽
- 시간 한 걸음 (전류 I>0 방전, 펌프 P):
  `dx = −η·I·dt/(F·Vc) + P·dt/(F·Vc) − (P_c+P_a)·Ag[m²]·2x·1000·dt/Vc`, `x` 를 ±(c0−0.002) 로 자름,
  반응 접촉면이 아니면 `q ← q − I·dt`

## 5. 보로노이 · 프랙탈 단면

창: 폭 W, 층 수 L, 높이 `Hw = L·t`, 결정핵 간격 `sp = t/g` (g = 층당 결정핵 수). 하나의 난수열(seed)을 아래 순서로 쓴다.

1. **결정핵**
   - `Ds ≥ 1.999`: `nx = max(2, round(W/sp))`, `nz = max(2, round(Hw/sp))`.
     j(행) 바깥, i(열) 안쪽 순서로 `x = (i+0.5)W/nx + uniform(−0.42,0.42)·W/nx`, `z = (j+0.5)Hw/nz + uniform(−0.42,0.42)·Hw/nz` (x 먼저).
   - 그 밖 (Soneira–Peebles): `m = 2^Ds`, `s0 = 16·sp`, `n0 = max(1, round(W·Hw/s0²))`.
     부모마다 `(u()·W, u()·Hw)`. 4단계 반복: (a) 모든 부모의 자식 수 `max(1, poisson(m))` 를 먼저 뽑고,
     (b) 자식마다 `부모 + (uniform(−h,h), uniform(−h,h))`, `h` 는 `s0/2` 에서 단계마다 절반.
     `x ← x mod W`, `z ← |z|`, `z > Hw` 이면 `2Hw − z`, `z` 를 `[Hw·1e-4, Hw(1−1e-4)]` 로 자름.
     `(floor(x/(sp·1e-3)+0.5), floor(z/(sp·1e-3)+0.5))` 가 같은 점은 처음 것만 남김.
2. **층 경계** (경계 n = L−1 개): `γ = 1.7`, `T = max(4, floor(ln(W/(sp/2))/ln γ) + 1)`,
   `a_k = γ^((D−2)k)`, `f_k = 2πγ^k/W`, `norm = sqrt(Σa_k²/2)`.
   위상: 경계마다 T 개 `uniform(0,2π)` (경계 바깥, 항 안쪽), 그다음 공통 위상 T 개.
   `h_b(x) = (b+1)t + ρt·(√κ·Σa_k cos(f_k x + φc_k) + √(1−κ)·Σa_k cos(f_k x + φ_bk))/norm` (ρ=0 이면 `(b+1)t`).
   결정핵 층 번호 = `z > h_b(x)` 인 b 의 개수.
3. **보로노이**: 창 [0,W]×[0,Hw] 안의 보로노이 (경계는 반사 = 창 경계에서 잘림). 길이 ≤ 1e-9 mm 인 벽은 버림.
   Python 은 거울상 4벌 + Qhull, Rust·C# 는 반평면 절단(Sutherland–Hodgman) — 같은 기하.
4. **회로망** (깊이 1 mm): 도메인 i,j 사이 벽(길이 L, 결정핵 거리 d), `Δ = layer_j − layer_i`, 아래층 `lo` 짝수 → CEM 아니면 AEM.
   - `|Δ|=1`: 벽 저항 = 해당 막, 기전력 `e_ij = sign(Δ)·α·Vt·ln(cB/cA)` (막 하나분), 그 외 벽 저항 = 두 막 평균, `e = 0`
   - `R = r_wall[Ω·mm²]/L + d/(2σ_i L) + d/(2σ_j L)` (σ 는 S/mm, 층 짝수 = cA, 홀수 = cB)
   - 아래 접촉(전위 0): 아래 경계 변 길이 Lc, `Gc = 1/(max(z_i,1e-3)/(σ_i·max(Lc,1e-9)) + 1e-3)`, 위 접촉(노드 T)도 같은 식 (`Hw − z_i`)
   - KCL: `Σ_j G(φ_i − φ_j) = −Σ_j G·e_ij`. 개방전압 = φ_T, 테브난 저항 = EMF 0, T 에 1 A 주입 시 φ_T,
     개방 손실 `P = Σ G(φ_i + e_ij − φ_j)²`
   - 이웃 수 평균: `2t < x < W−2t`, `2t < z < Hw−2t` 인 도메인의 벽 수 평균
5. **환산**: `V = V_win·(2N)/(L−1)`, `R = R_win·(2N/L)·W/(Ag·100)`, 누설 `P·(2N/L)/(W/(Ag·100)) / V`

## 6. 대사 (에너지원)

- 빛: `Φ = I[mW/cm²]·1e-3 / (hc/λ)`, 쌍당 펌프 `e·Φ·QE·(π·D/10·min(δ, D/2)/10)` [A], 하루 중 `t mod 24h < day_hours` 동안만
- 연료: 쌍당 `ν·F·(k/86400)·(c_f·1e-3·Vc[L])·남은비율`, 남은비율 `← ·exp(−k·dt/86400)`.
  연료전지형 접촉면이면 반응 접촉면(q 고정, 이중층 전압 0, ASR 30 Ω·cm² ×2 추가)
- 증발: `Pe = v·H/D_s` (v = mm/h → m/s), `r = min(e^min(Pe,50), 6.1/c0)`, `E_evap = ½(α_c − α_a)·Vt·ln r`
- 화학 전력 = 쌍당 펌프 × `N·E`

## 7. 부하

- LED + 직렬 저항 470 Ω (LED 보호용 표준 구성): `nVt = 2·0.025693`, `Is = 1e-3/exp(1.85/nVt)`, `V = nVt·ln(I/Is + 1) + 470·I`; 켜짐 ≥ 20 µA, 또렷 ≥ 0.5 mA
- 꼬마전구 2.5 V 0.3 A: `R_hot = 8.333 Ω`, 저항은 `R ← R_hot(0.1 + 0.9·min(I²R/0.75, 1.5)^0.6)` 를 R=0.1·R_hot 에서 30번 반복,
  `V = I·R`; 빛남 ≥ 정격의 15 % 전력
- 동작점: `OCV/k − I·R/k² = V_load(I)` 를 `[0, (OCV/k)/(R/k²)]` 이분법 100번 (k = 병렬 조각 수)

## 8. 시뮬레이션

`n = 0..steps` 마다: 동작점 I → 기록 → `step(I/k, dt, 펌프(t))` → 연료 소모. LED: 168 h, dt 60 s.
전구: k = 1..min(64,N) 중 시작 전력 최대, 2 h, dt 2 s. "처음 꺼짐" = 기록 간격 무관하게 첫 꺼짐 걸음의 시각.

## 10. 층 쌓기 레시피 재료량 (비교용 · 기준 사례에서 제외됨, `snss_battery/recipe.py`)

| cA, cB, 비 | S/d, 2S − cA, cB/cA |
| 넓이(cm²), 층 부피(mL), 높이(mm) | π(D/20)², 넓이·t/10, P·(2t + 0.013) |
| A·B 액 각각 v, 절반 h | 층 부피 · P · s, v/2 |

| A액 식염수 / 물 | h·2cA/S, h − 그 값 |
| B액 추가 NaCl (g) | (2cB − S)·h/1000·58.44 |
| 벽액 총량 W | P·w·s; CEM GO 0.9W, PVA 0.1W; AEM GO W·a/4, PDDA W·p/20, 물 = 나머지 |
| 구매량 | 식염수 = A액 식염수 + h, GO = 원액·CEM·AEM 합, PVA = 원액 PVA + 0.1·CEM PVA |
| 결정 예측 | §4 병 사례: 채움 = 넓이·높이/10 mL, 병 지름 D + 1.6, GO g, 층 t, 비 cB/cA, 수축 0 → 개방전압·내부저항, LED+470 Ω 동작 전류 (§7) |
