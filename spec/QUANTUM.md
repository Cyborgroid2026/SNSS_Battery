# SNSS-QB 양자 모듈 명세 (Python · Rust · C# 공통)

생리식염수 결정 배터리 자체는 양자 배터리가 될 수 없다 (상온 물속 이온, 결맞음 ≈ fs).
이 문서는 **별도 모듈**인 금속 무함유 유기 미세공진기 Dicke 형 양자 배터리의 계산·형상 명세다.

## 1. 물리 모델 — Tavis–Cummings 충전기 (공명, 회전파 근사)

- 분자(2준위) N 개 + 공진기 광자 1 모드. 충전 시작 상태: 광자 N 개 `|N⟩`, 분자 모두 바닥 `|j=N/2, m=−j⟩`.
- 들뜸 수가 보존되므로 기저 `k = 0..N` (분자로 옮겨간 들뜸 수): `|N−k⟩_ph ⊗ |m = −j + k⟩`.
- 해밀토니언 (ħ = 1, 결합 g = 1 단위, 공명이라 대각은 0): `H[k,k+1] = H[k+1,k] = (N−k)·√(k+1)`
- 저장 에너지 `E(t) = Σ k·|c_k(t)|²` (ħω 단위), 최대 `N`.
- **비교 기준 (병렬형)**: 분자 1개 + 광자 1개 짜리 N 개를 따로 충전 → `τ_par = π/2`, `E = N`, 평균 전력 `P_par = N / τ_par`.

## 2. 수치 적분 (세 구현 동일)

- 복소 진폭 `c` 를 고전 RK4 로 `dc/dt = −i·H·c` 적분. 시간 간격 `dt = 0.02 / ‖H‖∞` (`‖H‖∞` = 행 절댓값 합의 최대).
- 충전 시간 `τ`: `E(t)` 가 처음으로 극대가 되는 걸음 (다음 걸음에서 줄어드는 첫 걸음)의 시각. 그 걸음의 `E` 를 `E(τ)`.
- 평균 전력 `P = E(τ)/τ`, 집단 이점 `Γ = P / P_par`.
- **에르고트로피** (꺼내 쓸 수 있는 일): 광자를 무시한 분자 상태는 `k` 기저에서 대각 `p_k = |c_k|²`.
  전체 2^N 공간의 수동 상태 에너지 = `1 − max_k p_k` (가장 큰 확률은 0 에너지 1개, 나머지는 에너지 1 준위 N 개에 들어감).
  `W = E(τ) − (1 − max p)`.
- 지수 피팅: N 목록에 대해 `ln τ` 대 `ln N` 최소제곱 기울기 = `−a` (τ ∝ N^−a).

기준 N 목록: 1, 2, 4, 8, 16, 32, 64, 128.

## 3. 실제 소자로 환산

- 집단 라비 분열 `ħΩ_R` (측정값, 기본 0.10 eV) → `g√N_mol = Ω_R/2`.
  시뮬레이션의 `τ·√N` (N=128 값) 을 상수로 써서 `τ_real = (τ√N)/(Ω_R/2)`.
- 결맞음 유지 조건: `τ_real < T2` (분자 위상 이완, 기본 50 fs) **그리고** `τ_real < τ_cav` (광자 수명, 기본 Q=150 → `Q/ω`).
  둘 다 만족하면 "양자 이점 유효", 아니면 "고전 충전과 구별 불가".
- 분자 수: 활성층 부피 × 색소 농도 (1 wt% in PMMA, ρ 1.18 g/cm³, 분자량 1080 g/mol) × N_A.
  최대 저장 에너지 `N_mol · hc/λ` (λ = 590 nm). 저장 수명 = 색소 들뜸 수명 4 ns (초방사로 더 짧아질 수 있음).

## 4. 모듈 형상 (CAD, 단위 mm, 아래에서 위로)

| 층 | 재질 (원소) | 지름 | 두께 |
|---|---|---|---|
| 기판 | 용융 실리카 SiO₂ (Si,O) | 25.0 | 1.0 |
| 아래 거울 ×8쌍 | SiO₂ 101.03 nm / Si₃N₄ 73.75 nm (Si,O / Si,N) | 24.0 | 쌍마다 1.7478e-4 |
| 활성층 | PMMA + 페릴렌 다이이미드 색소 1 wt% (C,H,N,O) | 24.0 | 1.9799e-4 (λ/2n, n=1.49) |
| 위 거울 ×8쌍 | 아래와 같음 (Si₃N₄ 먼저 → SiO₂) | 24.0 | 쌍마다 1.7478e-4 |
| 덮개 | 용융 실리카 | 25.0 | 0.5 |

층 두께: 1/4 파장 `λ/(4n)` (λ 590 nm, n_SiO₂ 1.46, n_Si₃N₄ 2.00). 각 층은 하나의 원기둥 고체(B-rep)이며, STEP(ISO 10303-21, AP214)으로 내보낸다.
CAD 검증: OpenCascade 로 읽어 고체 수 = 35, 모든 고체 유효(BRepCheck), 부피 합 = 해석값 (상대 1e-6).
